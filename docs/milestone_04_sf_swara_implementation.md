# Milestone 4 – SF-SWARA Implementation

## Objective
Implement the SF-SWARA methodology (Equations A10–A15).

## Workflow
Expert Evaluations
    ↓
SWAM (A10)
    ↓
Score Function (A11)
    ↓
Rank Criteria
    ↓
Comparative Importance (A12)
    ↓
Comparative Coefficients (A13)
    ↓
SF Weights (A14)
    ↓
Normalized Weights (A15)

## Inputs
- Criteria DataFrame
- Evaluation DataFrame
- Linguistic lookup
- Expert weights

## Outputs
- Aggregated SFNs
- Scores
- Ranking
- Comparative importance
- Comparative coefficients
- SF weights
- Final normalized criterion weights

## Outcome
SF-SWARA produces the criterion weights required by SF-EDAS.
